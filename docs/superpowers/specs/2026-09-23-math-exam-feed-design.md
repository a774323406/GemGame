# 手写口算推荐流小游戏

用户希望依据所附 26 秒竖屏视频，在 GemGame 中新增推荐流游戏。视频中的交互是红笔手写口算答案、正确后加 5 分并滚动试卷。沿用项目 Cocos Creator 3.8.5、750×1624 竖屏、gamescene bundle、大厅卡片和推荐流服务。

## 视觉修订（用户明确要求按视频原图还原）

使用参考视频的原画图层和原始数字字形，按 592×1280 坐标对齐。保留“2023年数学竞赛A卷”标题、木桌、黄色衬纸、胶带、修正液和原按钮图案。仅移除动态图文所在区域；原始四道题作为开局，后续随机补题。取消首版新增的装饰和教程文字，计时改为原表盘指针，擦除改为按住并拖动修正液，让瓶嘴局部擦除红色笔迹，松手回位。短屏等比完整显示。

## 玩法设计

- 名称：口算大挑战。暖色木桌、白色试卷、红色笔迹；四道可见题目，第一题是当前答题区。
- 每局 60 秒，每题 5 分，以 100 分为挑战目标；到时显示成绩、答对题数和最佳成绩，可再玩或回大厅。
- 加减乘法使用 0～9 操作数，减法无负数，答案 0～81。开局按视频的四道题，之后随机混入加减乘法；不连续重复题目。
- 鼠标和触摸均可书写。数字识别离线执行，与正确答案完全独立。停笔后识别并自动判题；错误留在原题，不扣分，可擦除重写。低置信度不强行判为某个数字。
- 使用多模板点云匹配，兼容单笔和常见多笔数字；只识别 0～9，不宣称任意字迹都能可靠识别。显示识别结果，让用户能确认错误来自口算还是识别。
- 所有固定界面及按钮在 .scene 中序列化，红笔笔迹和时钟指针由 Graphics 动态绘制。根布局按可视高度缩放，短屏和长屏都保留答题区、按钮和结算。
- 正确反馈由分数数字更新、短音效和 0.2 秒滚卷组成。动画结束后才启用下一题输入，重开及销毁必须取消旧动画。

## 集成与边界

- 新增 MathExamFeedGameScene、独立回合规则和笔迹识别模块；注册场景 UUID，大厅新增卡片。
- 新推荐流 Content ID 由平台分配，目前配置为空字符串并带非空判断，不占用现有投放 ID。大厅可直接试玩；取得真实 ID 后只需改一处配置。
- 推荐流预览不计时，正式进入重置一局；首次触摸兼容宿主回调缺失；后台、退出推荐流和全屏广告期间不计时、不接收书写。
- 重复进入通知不重复重置；离开完成一次会话，取消插屏及事件监听。遵循现有音效开关与平台服务。

## 验收

规则测试覆盖答案、零、两位数、非法输入、计时结束、重开。识别测试使用独立手写坐标样本、平移缩放、多笔和噪声，避免只用内置模板自测。真实 Cocos 浏览器预览验证画面、触摸书写、自动判题、擦除、结算、重玩和大厅进入；检查至少 750×1334 与 750×1624 两种视口。回归现有推荐流和大厅测试，记录实际无法验证的真机部分。
