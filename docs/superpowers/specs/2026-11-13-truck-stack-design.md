# 货车叠叠高设计

## 已确认范围
- 新增推荐流玩法，参考 f1939c101e47afedac7e843109638797.mp4 的第一段：吊箱落到红色货车。
- 无尽叠高，记录最高高度；不做视频的 9 米通关。
- 游戏中返回与底部广告减速；失败全屏结算，可广告复活或重玩。
- 沿用当前 kdzzz 的循环插屏机制，插屏不主动暂停游戏。
- 新增包体预算不超过 1 MB。只改源码，由用户构建和真机测试。

## 实现选择与假设
新增 `TruckStackFeedGameScene` 和大厅入口“货车叠叠高”；推荐流 ID 暂用 `xx`，不覆盖任何当前 ID/广告 ID。
Cocos 3.8.5 当前未启用 2D 物理；采用纯 TypeScript 固定步长摆动/自由落体/支撑判定，避免引入物理运行库。完整刚体方案会增加体积和不稳定因素；单纯按钮计数不能呈现视频中偏心倾倒，因此不采用。
美术采用可重建的简洁线稿矢量转小 PNG：奶油背景、红色平板货车、黄褐纸箱、深色胶带、细黑吊绳和白云。共用现有按钮、音效与 getUserBgm，不新增大音频。

## 玩法
- 初始车上放一箱（1 米），每落稳一箱增加 1 米。
- 只在吊箱摆动时接受点击，释放后沿重力下落；悬吊箱保持水平。
- 落箱中心需要足够支撑。中心稳定时落稳；边缘支撑不足则先倾倒，再落出画面失败。支撑判定在实际着陆位置执行，不偷偷移动玩家的箱子。
- 完美落点有小幅压缩回弹、尘点、短音效；失败有旋转掉落反馈。
- 难度随落稳箱数增加：摆速逐渐变快但封顶；摆幅始终覆盖可用落点。
- 镜头向上追随顶箱。只保留最近约 18 箱的渲染/状态，累计高度独立保存，无尽游戏内存有界。
- 看完广告减速 20 秒，摆速为 50%；不改变重力或支撑规则；未看完不给奖励。
- 复活保留已落稳箱子和高度，移除失败箱，重新生成可操作的吊箱。可反复重玩和复活。
- 最高纪录每次增加就持久化，避免中途退出丢失；异常存储值回退。

## 生命周期与 UI
- 默认 750×1624、固定宽度；验收 750×1334 和 750×1624。
- 返回放左上，打开确认/暂停层：继续、重新开始、退出本局。
- 减速按钮底部安全区内，含视频标识及状态文本。
- 结算使用 tools/feed_result_layout.mjs：全屏黑色 145/255 遮罩、大标题/描边正文/大胶囊按钮，收起 HUD，背景保留。
- 推荐流预览保持吊箱摆动和 BGM，不能落箱或计分；稳定渲染后报告就绪，不能等待 feedEnter 才报告就绪。
- 显示插屏不暂停玩法；仅离开/后台、返回菜单、激励视频会暂停。实际触摸能恢复迟到的 feedEnter 状态。
- 激励回调用令牌抵御退出、销毁、重开等过期回调；场景销毁清理监听和插屏会话。
