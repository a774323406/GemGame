# 空投救援推荐流玩法设计

## 意图

新增一个与参考视频同类的推荐流玩法。玩家划线剪断直升机吊着蔬菜的绳子，让蔬菜落入下方玻璃瓶，帮助瓶中的小猪获得食物。玩法重点是多架直升机从屏幕外进出、多个蔬菜同时下落，以及瓶口接取的即时判定。

## 已确认范围

- 目标场景名暂定为 `AirdropRescueFeedGameScene`。
- 本关不限时，不显示倒计时；显示食物 `0/5` 和机会 `25/25`。难度按实际游玩时长提升，推荐流预览停留不提升难度。
- 直升机从屏幕外左右进入，数量和出现间隔随机，可同时存在多架。
- 每架直升机携带一份蔬菜。按下记录起点，拖动时显示起点到当前点的一条直线；松手时，用起点与松手点之间的直线检查当时的吊绳位置，命中才释放蔬菜。拖动途中不切绳，只点击不释放，一次直线可以剪断多条绳子。
- 未点击的直升机和蔬菜飞出屏幕后直接回收，不扣机会。只有已经释放的蔬菜落空或越过场景底部才扣机会。
- 蔬菜落入瓶口判定区域时食物加一，随后继续进入瓶颈和瓶身，落到底部并保留。落到瓶外或屏幕底部时机会减一。
- 接满 5 份食物成功，机会归零失败。
- 底部只保留一个带广告标识的“减速”按钮。用户确认：完整看完广告后，所有直升机（包括突然加速的飞机）速度减半，持续 20 秒，结束后可再次使用；时长在场景组件中可调整。
- 加入 `NewMainScene` 主界面。推荐流 ID 配置保留 `xx` 占位，但未知或占位值不参与正式路由，补入真实 Content_ID 后再开启推荐流入口。
- 资源预算允许超过 1 MB，以画面效果为优先。
- 结算复用项目现有推荐流全屏结算规范，不使用视频中的弹窗样式。
- 推荐流插屏、激励视频、返回按钮、背景音乐和结算按钮复用现有框架。插屏不主动暂停游戏。

## 目标

- 画面结构、运动节奏和操作反馈接近视频。
- 支持多目标并行运动和多颗蔬菜同时下落。
- 瓶口判定稳定，命中与落空都能在同一帧状态更新中正确扣分或加分。
- 运行时不依赖临时创建固定 UI，固定界面节点可在 Cocos Creator 中编辑。
- 短屏和长屏都能保持标题、状态、瓶子和底部按钮的安全边距。

## 非目标

- 不复刻视频里的弹窗式结算，不新增“喊人”按钮。
- 不修改拼豆 `GameScene` 或其他已停止维护的玩法。
- 本轮不执行 Cocos 构建，由用户自行构建测试。

## 实现方案

### 方案 A：完整复刻视频

为直升机、蔬菜、玻璃瓶和小猪制作独立素材，并为所有固定 UI 建立专用序列化场景。画面最接近视频，但素材和场景制作成本最高。

### 方案 B：轻量程序绘制

复用现有背景和按钮，主要角色用运行时节点与简单贴图组合。包体最小，但玻璃瓶、直升机和角色质感会明显偏离视频。

### 方案 C：混合方案（已选择）

复用现有推荐流背景、标题、按钮、广告标识和结算框架，为直升机、蔬菜、玻璃瓶和小猪制作轻量透明素材。多架直升机与蔬菜使用对象池，场景 UI 序列化到 `AirdropRescueFeedGameScene.scene`，动态部分由脚本驱动。该方案在视频相似度、开发量和资源体积之间取平衡。

## 玩法结构

### 场景层级

- 顶部返回按钮、标题牌。
- 标题下方说明牌“空投食物救救小猪”。
- 左侧食物计数，右侧剩余机会。
- 中部天空、云层、直升机生成区、瓶口和瓶身。
- 底部草地与居中的减速广告按钮。
- 全屏结算覆盖层由 `feed_result_layout.mjs` 维护。

### 目标对象

每个目标保存直升机位置、水平速度、吊绳长度、蔬菜位置、状态和生成序号。目标从屏幕外生成，进入可视区域后横向移动，离开另一侧后回收。拖动期间只预览一条起终点直线，松手时该线段与吊绳相交才从“悬挂”切换到“下落”，蔬菜保留当时的水平速度并叠加重力。飞机移入独立飞离队列，继续向原方向前进并略微升高，完全离屏后才回收，蔬菜是否已接住或落地不影响飞机飞离。

### 接取判定

瓶口使用独立的窄矩形判定区。蔬菜下落穿过瓶口时，按蔬菜中心点和瓶口宽度判断入口命中，每颗只加一次食物并播放接取反馈。命中后移入独立的瓶内食物队列，保留原位置和朝向，从瓶颈继续落入瓶身；使用窄颈、圆形瓶身和蔬菜之间的轻量碰撞约束，避免穿透瓶壁或全部重叠在一个点。瓶内蔬菜绘制在小猪和玻璃轮廓后面，复活保留，重玩清空，结算画面仍保留其下落与堆叠。落到瓶外或屏幕底部的蔬菜才扣机会并回收。

### 随机节奏

前段以单架为主，随后随机混合单架与双架，缩短生成间隔和扩大速度差。所有生成点都在屏幕外侧，避免目标凭空出现在屏幕内。难度在前 120 秒实际游玩内逐步提升并封顶，不作为结束条件。

部分飞机在飞行过程中突然加速，各自的触发位置与倍率独立随机。默认调参：加速机概率从 25% 逐步提高到 55%，倍率约为原速的 1.7～2.5 倍，在 0.16 秒内提速并保持到离屏；触发位置位于可视区域。正常飞机仍会穿插出现。

减速统一作用于当前、新生成和剪绳后飞离的直升机，包括加速机；已释放蔬菜保留剪断瞬间的实际速度，之后不受飞机加速或减速结束影响。暂停、切后台和激励广告期间不消耗减速时长；推荐流预览不推进难度时钟。

### 失败、复活和广告

失败时显示本局食物数和结算按钮，按现有推荐流规则提供激励视频复活或重新挑战。复活不限次数，每次完整看完激励广告后保留已接到的食物，机会恢复为 5 次并继续当前场面。减速和复活沿用现有广告标识与广告调用封装，只有完整看完激励广告才发放效果。插屏展示不主动暂停游戏，激励视频保留现有暂停保护。
