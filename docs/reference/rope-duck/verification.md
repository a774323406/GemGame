# 双鸭跳跃验证记录

2026-11-10，Cocos Creator 3.8.5。

## 已实现

- 独立推荐流场景及大厅入口，临时推荐流 ID `xx`。
- 按住蓄力、松手起跳、优先轮流、另一只悬空时控制落地鸭子、绳长约束；断崖、尖刺、能量收集和冲刺。
- 游戏内只有返回按钮；返回确认暂停；失败全屏结算、激励复活、重新挑战、返回主页。
- 共用重复插屏流程，不主动暂停玩法；后台、返回确认和激励广告暂停。
- 共用 `getUserBgm`、音乐/音效开关；预览待机动作和背景音乐。

## 操作方式判断

原视频没有触点标记，无法仅凭画面证明按压时长。根据用户倾向与不同跳跃距离采用用户确认的 0.2 秒满蓄力；后续若确认原版输入不同，可单独调整输入层。
