# 推荐流全屏结算规范

2026-09-25 用户确认的长期约定。适用乒乓球、企鹅、打瓶子、外卖、套大鹅、节奏猫、口算、摩托及后续推荐流；本轮不改拼豆。

游戏画面保持在后方，Canvas 层使用纯黑色、145/255 不透明度的全屏遮罩拦截点击。结算容器没有背景框、描边、圆角面板，也没有整体缩放弹出动画。成功标题使用浅金色，失败标题与正文用白色。标题在屏幕上方，统计和插画居中，彩色胶囊按钮在下方纵排（企鹅复活橙、下一关绿、重玩蓝；猫咪重玩粉；其他默认橙），保留激励视频角标。摩托暂停页也采用此布局，继续比赛只在暂停时出现。企鹅删除喊人入口。

`tools/feed_result_layout.mjs` 是共同的离线布局规则。遮罩与内容容器通过 Widget 铺满 Canvas；标题、正文和按钮通过相对屏高的居中 Widget 定位。各玩法仍负责状态、按钮显隐、奖励和广告，不在布局工具里增加游戏行为。生成器必须调用共同规则，避免编辑器中的改动在重建后丢失。

校验：`node tools/test_feed_result_layout.cjs`，各玩法 controller/scene 测试，以及 Creator TypeScript 检查。真机发布前仍应检查平台安全区、广告返回与不同屏幕比例。
