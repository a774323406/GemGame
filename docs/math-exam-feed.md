# 口算大挑战

根据参考视频实现的 Cocos Creator 3.8.5 竖屏手写口算游戏。

## 试玩

- 大厅卡片：口算大挑战。
- 独立场景：`assets/gamescene/MathExamFeedGameScene.scene`。
- Cocos 编辑器运行期间可打开 `http://localhost:7456/?scene=16cb5b67-1cc4-5e8f-a42e-1af87bf65a0e`。
- 每局 60 秒，答对加 5 分，目标 100 分；在第一题右侧写答案，停笔约 1 秒自动识别并判题。支持一位、两位手写数字；识别错误可按住左下角涂改液，拖动瓶嘴擦掉经过的红色笔迹，再重写。松手后瓶子回位。
- 底部“加时”使用与外卖玩法相同的方形仪表盘按钮，右上角带广告角标，完整观看一次激励视频后增加 30 秒；失败成绩单提供带广告标识的“复活”按钮，保留分数、当前题目和未提交笔迹继续作答。挑战成功不显示复活。
- 广告请求和播放期间暂停倒计时、识别及涂改操作，并禁止重复点击、重开与返回。提前关闭、播放失败不给奖励；退出推荐流、重开或销毁后到达的旧回调不会影响新回合。
- 加减乘法答案为 0～81；识别完全在本地运行，不上传笔迹，也不把正确答案提供给识别器。

## 编辑与重建

固定界面、题目、按钮及结算都序列化在场景中，可以直接在 Creator 编辑器调整。题目使用从视频提取的位图字形。红色笔迹和动态时钟指针在运行时绘制。

```sh
node tools/build_math_exam_scene.mjs --write --replace-scene
```

上述命令会重建口算场景，覆盖此场景的手动排版调整；大厅卡片只在缺失时添加，不覆盖已有大厅布局。该脚本复用视频原画，不会重新生成或替换画风。视频原帧和局部清理稿在 `docs/reference/math-exam/`；需要重建图集时先执行 `node tools/prepare_math_exam_art.mjs`。无新增外部运行库。
